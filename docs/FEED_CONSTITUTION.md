# Feed Constitution

PR-00/PR-01 contracts documentation and deterministic fixtures only. Runnable feed generation and client UI are deferred.

1. Following/chronological access remains available.
2. Feeds are removable, replaceable, and versioned.
3. No default ranking optimizes raw engagement as its sole objective.
4. The active provider, algorithm version, and material changes are visible.
5. Explicit preferences dominate inferred behavior.
6. Ideological classification is not a default integrity signal or quota.
7. **Personalization sovereignty:** a feed service does not require private behavioral history to provide personalized ranking; private model state is local by default.
8. **Integrity separation:** integrity discounts correlated evidence; it is not a content judgment or moderation action.
9. **Viewpoint neutrality:** political, religious, and philosophical classification cannot drive default integrity weighting.
10. **Explanation fidelity:** explanations derive from the deterministic ranking trace that produced placement.
11. **Credible exit:** changing providers does not require changing DID, PDS, public graph, or portable explicit preferences.
12. “More,” “less,” seen state, dwell, scroll, hover, and affinity signals remain local by default.
13. Experiments with material objective changes are separately named and opt-in.
14. Provider failure offers cached results and an explicit switch; no silent fallback.

Advanced provenance attestations, signed candidate batches, custom candidate protocol, longitudinal audits, and runtime verification are future guidance.
