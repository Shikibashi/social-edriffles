# Attention Sovereignty UI v1

The supported client exposes account-scoped attention controls through Personalization & data. Discovery, variety, freshness, and exploration are explicit settings persisted locally; inferred topics can be inspected and removed. Existing export/import, encrypted backup, and reset actions remain available.

`FeedProvenanceCard` distinguishes feed name, algorithm/version, provider/provider DID, manifest status, objective, privacy, and service health. Provider circuit breaking, stale data, degradation, and fallback are represented as visible health states; provider selection remains explicit.

`publicRankingTrace` maps local Balanced categories to truthful Why-this-post labels and explicitly omits confidential integrity signals. Quiet Metrics behavior is documented as hiding counts/trending prominence while preserving the user's own likes. Controls use accessible labels, live-region health announcements, and standard focusable pressable settings items.
