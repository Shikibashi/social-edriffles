# Layout delta: Edriffles Computer Web identity

This is a global identity-layer delta, not a new page or information
architecture change. The existing shell, Communities route, login flow, and
responsive geometry remain in place.

## Surface mapping

| Existing surface | Identity change | Layout impact |
| --- | --- | --- |
| Browser chrome | Favicon, Apple touch icon, pinned-tab icon | None |
| Prepaint splash | Inline Edriffles mark | Same centered footprint |
| Auth splash | Square emblem plus lowercase wordmark | Same vertical stack |
| Shared logo components | Web-only Edriffles image/text branches | Square mark; callers retain their target size |
| Server shell | Edriffles title, metadata, and mark | None |
| Share cards | Edriffles emblem, wordmark, descriptor | Same 1200x630 composition |

## Responsive rule

The brand lockup remains legible at the existing desktop and mobile sizes. The
web splash always uses a 92px mark and a 161px wordmark; the detailed emblem is
not scaled into a new hero or decorative background. Existing ECW container,
focus, reduced-motion, and color-mode rules remain authoritative.

## Render review exemption

Three competing page compositions are not required because this work changes
only the identity layer within an already approved shell. The emblem, light
share card, and dark share card are the three visual identity states reviewed;
no page hierarchy or task flow was changed.
