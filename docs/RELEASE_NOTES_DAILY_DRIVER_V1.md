# Daily Driver v1 Release Notes

Daily Driver v1 provides the existing social-app web client with normal authentication, profiles, timelines, threads, search, associations, explicit service/provider selection, attention controls, Identity Sovereignty surfaces, and Portable Personalization contracts.

The browser deployment path is the supported Linux experience. Identity migration repository/blob transfer remains simulated, identity endpoint updates remain upstream-constrained, and public resolver probes were skipped in the current environment. These limitations are visible in the feature matrix and UI capability labels.
